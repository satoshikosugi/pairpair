# PairPair 問題点と改善タスク

更新日: 2026-06-13

## 優先度 High

- `pnpm` 前提が強く、`npm test` が環境によって失敗する
  - 対応: `corepack` 前提を README に明記し、CI でも `pnpm` を固定する
- signaling server URL が renderer に直書きされている
  - 対応: 環境変数または設定ファイルへ移す
- `infra/redis.ts` が in-memory 実装なのに名前だけ Redis
  - 対応: ファイル名と README を実装に合わせて整理する

## 優先度 Medium

- `apps/desktop/src/renderer/src/*` に古い足場コードが残っている
  - 対応: 現用コードへ統合し、未使用ファイルを削除する
- ホストオーバーレイは共有ウィンドウ単位ではなくディスプレイ単位
  - 対応: ウィンドウ共有時の座標系と bounds を個別に扱う
- 全画面中の単発 `ESC` はホストへ送られずローカルで握りつぶす
  - 対応: 2回目が来なかった場合だけホストへ送る遅延送信にする

## 優先度 Low

- 注釈の永続化やホスト側からの編集は未対応
  - 対応: 必要なら host/guest 双方向編集に拡張
- 注釈ツールに図形やハイライトはない
  - 対応: 直線、矩形、スポットライト等を追加
- E2E テストが不足
  - 対応: Electron + Playwright で接続、操作、全画面、注釈を自動検証

## 改善タスク案

1. 接続先 URL と STUN/TURN 設定を環境変数へ移す
2. `infra/redis.ts` を `session-store.ts` へ改名する
3. 未使用 renderer 足場コードを削除する
4. `pnpm` 固定の CI とセットアップスクリプトを整備する
5. 注釈と全画面の E2E テストを追加する
6. 共有ウィンドウ時のホストオーバーレイ位置合わせを改善する
